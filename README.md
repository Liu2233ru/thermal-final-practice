# 热学期末模拟 V4

[打开网页版](https://liu2233ru.github.io/thermal-final-practice/)即可练习。也可把便携版解压，打开其中的 `index.html`。

- **模拟考试**按 2025–2026 A 卷结构抽取 60 题，满分 100 分。1 分单选 28 题、2 分单选 19 题、2 分多选 5 题、3 分单选 8 题。多选全对得 2 分，仅漏选得 1 分，错选或空答得 0 分。
- 勾选「跳过做过的题」可排除已交卷且已作答的题。组卷后限时 100 分钟，超时后可继续作答，提交时记录实际用时。
- **题库全览**可以按关键词、来源、题型和分值查找，打开任意一题查看答案与解析。题干和选项采用文字及 KaTeX 公式，原图用于示意图。参考资料只提供必要常数、换算或积分表。
- **考试记录**保存每次 V4 交卷的用时、逐题作答、正确选项和得分，可筛选错题、部分得分或漏答，并查看题型和分值表现。旧版记录仍可查看已有的成绩摘要。
- **错题复习**直接展示题干和来源。移出一道错题后，仍可在已做题中查看，且「跳过做过的题」仍会排除它。以后再答错或部分得分时会重新收录。
- 做题记录保存在当前浏览器中。换电脑或浏览器可先在首页导出记录，再在新环境导入。首页也可以清空当前浏览器的记录。

`dist` 是可直接托管的静态网站。运行 `node --test tests/*.cjs` 可检查题库、公式、组卷、判分和记录。
