# 热学期末模拟

打开网站即可开始模拟考试。下载整个仓库后，也可解压并双击 `index.html` 在浏览器中使用。

- 每套卷 60 道计分题，满分 100 分，按 2025–2026 A 卷的题型和分值比例抽题。
- 多选全对得 2 分，只漏选得 1 分，勾选错误选项或空答得 0 分。
- 「跳过做过的题」会排除已交卷且实际作答过的题。某类题不足时，首页会提示缺少的题量。
- 组卷后倒计时 100 分钟。刷新或恢复答题时继续计时。超时后仍可答题，手动交卷。
- 题干和选项中的公式以 KaTeX 排版。部分计算题可以展开参考公式，展开不计分。
- 做题记录保存在当前浏览器。换电脑或更换网址时，可以在首页导出记录，再到新环境导入。

如需用 GitHub Pages 托管，可选择 `main` 分支的根目录作为发布来源。
