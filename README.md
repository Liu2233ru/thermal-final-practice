# 热学期末模拟

[打开模拟考试](https://liu2233ru.github.io/thermal-final-practice/)即可开始练习。下载仓库后，也可解压并在浏览器里打开 index.html。

- 题库有 619 道题，包含历年卷、去重后的 450 题库题目和两本教材的专题改编。每卷按 2025–2026 A 卷配额抽取 60 题，满分 100 分。
- 参考公式仅提供必要常数、单位换算或积分表。交卷后可查看答案和已有的解析。
- 「错题库」收录答错和部分得分的题，「已做题」可回看曾作答的题。「跳过做过的题」会在组卷时排除这些题。
- 组卷后倒计时 100 分钟。超时后仍可答题并手动交卷。
- 记录保存在浏览器中。换电脑时可以在首页导出和导入记录。
